## Overview

SeatX is a sleek, native iOS and macOS application built with SwiftUI for managing seating experiences. Whether you're organizing events, managing venues, or optimizing workspace layouts, SeatX provides an intuitive interface for visualizing and managing seating arrangements.

## Features

| Feature | Description |
|---------|-------------|
| 🪑 **Seating Management** | Create and visualize seating charts |
| 📱 **Cross-Platform** | Native support for iOS and macOS |
| 🎨 **Modern UI** | Built with SwiftUI for a native experience |
| ⚡ **Real-time Updates** | Dynamic layout adjustments |
| 📊 **Analytics** | Track attendance and seating trends |

## Installation

### From Source

```bash
# Clone the repository
git clone https://github.com/Seaus-tech/SeatX.git
cd SeatX

# Open in Xcode
open SeatX.xcodeproj
```

Then build and run with `Cmd + R`.

## Usage

SeatX provides an intuitive interface for:

1. Creating seating charts for events
2. Managing venue layouts
3. Tracking attendee preferences
4. Exporting layouts for printing

## System Requirements

- Xcode 15.0 or later
- iOS 17.0+ / macOS 14.0+ deployment target
- Apple Silicon or Intel Mac

## Codebase Structure

```
SeatX/
├── SeatX/                    # Main source directory
```
